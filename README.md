# Goals Fin

A financial goal OS: set targets, log progress, get offline AI insights, share snapshots, and receive local alerts.

## Unique ideas
- **Goal Momentum** — single score for velocity across goals (pace vs deadlines + completion)
- **Future Self** — short narrative insight from your numbers
- **Sacrifice focus** — how hard your monthly contributions lean into remaining targets
- Private by default — localStorage only; share only when you choose

## Features
- Onboarding + PIN + optional biometrics (WebAuthn)
- Goals CRUD, categories, deadlines, monthly pace
- Contribution history
- AI insights & recommendations (on-device)
- Share via Web Share API / copy
- Local notification preferences
- Export / import JSON backup
- PWA offline (service worker)

## Deploy
Upload entire folder to GitHub Pages (or any static host).  
HTTPS required for biometrics & installability.
